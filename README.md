# 🛍️ Customer Shopping Behavior Analysis

An end-to-end Data Analytics project that analyzes customer shopping behavior using **Python, PostgreSQL, SQL, and Power BI**. The project focuses on cleaning transactional data, performing feature engineering, extracting business insights using SQL, and building an interactive Power BI dashboard.

---

## 📌 Project Overview

This project analyzes **3,900 customer purchase records** across multiple product categories to understand customer behavior, spending patterns, product preferences, subscription trends, and purchasing frequency.

## 🧹 Data Cleaning

Performed the following preprocessing tasks:

- Loaded and explored the dataset using Pandas
- Handled missing values
- Standardized column names using snake_case
- Removed redundant columns
- Checked data consistency
- Created a clean dataset for analysis

---

## ⚙️ Feature Engineering

Created new features including:

- Age Group
- Purchase Frequency (Days)

These features improved customer segmentation and business analysis.

---

## 🗄️ SQL Analysis

Performed business analysis using PostgreSQL, including:

- Revenue by Gender
- High-Spending Discount Users
- Top Rated Products
- Shipping Type Comparison
- Subscribers vs Non-Subscribers
- Discount Dependent Products
- Customer Segmentation
- Top Products by Category
- Repeat Buyers Analysis
- Revenue by Age Group

---

## 📊 Power BI Dashboard

Built an interactive dashboard containing:

- Total Customers KPI
- Average Purchase Amount
- Average Review Rating
- Revenue by Category
- Sales by Category
- Revenue by Age Group
- Sales by Age Group
- Subscription Analysis

Interactive slicers include:

- Gender
- Category
- Shipping Type
- Subscription Status

---

## 💡 Business Insights

- Analyzed customer purchasing behavior across different product categories.
- Compared revenue generated by different customer segments.
- Identified top-performing products based on ratings.
- Evaluated subscription impact on customer spending.
- Examined shipping preferences and their influence on purchase amount.
- Segmented customers based on purchase history.
